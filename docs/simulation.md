# 2-player simulation results

Batch runs use the [`spacebase2p`](simulator.md) package: base game only, simplified card pool, three bots (`income`, `rush`, `random`). Charts below are generated by [`scripts/generate_simulation_plots.py`](https://github.com/pkfamily/space-base-strategy/blob/main/scripts/generate_simulation_plots.py) (regenerated on each Pages deploy).

{: .rocket }
**Headline:** rush bots beat income bots by a wide margin in this model — mostly **overspend** on always-buy income, not because income is useless on paper.

## Numbers (latest batch)

Values are written to [`summary.json`]({{ '/assets/plots/summary.json' | relative_url }}) when you run the plot script. Default: **400 games** per matchup, seed **42**, up to **800** turns per game.

Download or view **summary.json** on the deployed site for exact win rates and averages after each build.

## Seat (rush mirror)

Separate run: **2000** rush vs rush games — starter wins **~53%**, second seat **~47%** (P2 +1 gold).

## Caveats

- **Simplified deck**, not the full 132-card ship list.
- Bots are **heuristic** (income does not yet pass to avoid overspend).
- `random` vs `random` can hit the turn cap; the benchmark uses 800 turns.

```bash
pip install -e ".[dev]"
python3 scripts/generate_simulation_plots.py
python3 -m spacebase2p.cli -n 500 --p0 income --p1 rush
```
